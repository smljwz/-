**日志医生** 用来读日志、抽出报错，再让 DeepSeek 用中文说明原因和改法。

**使用前请先接入 API。填入 `DEEPSEEK_API_KEY`，否则只能筛日志，不能分析报错。

**功能**

- 读取指定日志（不写路径则用 `测试日志.log`）
- 筛出含 `ERROR`、`Exception`、`Traceback` 的行
- 把这些报错发给大模型分析
- 分析结果在终端里流式显示

在项目目录里打开终端，执行：
python main.py 测试日志.log
测试日志.log 换成你自己的日志路径也可以，例如：
python main.py D:\日志\app.log

**运行逻辑**

启动后先读参数和密钥 → 打开日志并检查文件是否可读 → 按行筛选关键词 → 先打印摘要 → 有报错才调用 DeepSeek → 一边生成一边输出。没有命中行就不调模型；没配 API、文件不存在或认证失败会报错退出。
